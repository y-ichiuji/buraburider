# プロダクトビジョン

「最速」ではなく「最高の道中」を提案する、バイク乗りのための体験特化型ナビゲーションアプリ。

## 1. ルート生成＆カスタマイズ機能

- **寄り道度スライダー**
- 目的地入力後、「どれくらい遠回りして道中を楽しみたいか」をパラメータで調整可能にする。
- スライダーの段階に応じて、周辺のワインディングロード、絶景ポイント、名所をAIが自動でルートに組み込んで再構築する。

## 2. スマート休憩スケジューリング機能

- **休憩の自動組み込み**
- 「1時間半ごと」など、ユーザーが設定した目安時間・疲労度に合わせて、ルート上の最適なタイミングに休憩スポットを自動挿入する。

- **気分で選べる休憩カテゴリ（モード選択）**
- **サクッと休憩モード（デフォルト）**: 駐車しやすく、短時間で用を足せるコンビニを優先。
- **ご当地満喫モード（デフォルト）**: ツーリングの醍醐味である道の駅や、特産品を楽しめるスポットを優先。
- **絶景・ライダーズカフェモード**: バイク乗り歓迎のカフェや、愛車と写真が撮れる景勝地を優先。
- **緊急ピットインモード**: GSや、暑さ・雨をしのげる屋内施設を優先。

## 3. 安全・快適ルーティング（酷道・悪路回避フィルター）

- **複合データによる危険路の自動回避**
- **オープンデータ活用**: 地図情報（OpenStreetMap等）の属性タグから、未舗装林道などを除外。
- **プローブデータ解析**: 制限速度に対してユーザーの平均通過速度が著しく低い区間を「酷道・狭小路」と判定して回避。
- **リアルタイム共有**: ユーザーからの「砂利・落ち葉・凍結」報告をマップ上に反映し、後続ユーザーのルートから自動で弾く。

## 4. 走行中の緊急アクション（SOSボタン）

- **常時固定の緊急割り込みUI**
- インカム通話の妨げにならないよう、ナビ画面の端に透過した「大サイズSOSボタン」を常時配置。
- 対象は「トイレ」「GS」「急な雨宿り（高架下・屋根付き）」の3種類とする。

- **グローブ最適化＆誤作動防止**
- 走行中の振動を考慮し、タップではなく「スワイプ」または「1秒長押し」で発動。

- **タイムロス最少の1発選定**
- 操作後、リストから選ばせる画面は出さず、現在のルートから最も外れない（タイムロスが少ない）スポットをAIが1つだけ即座に自動挿入する。

- **シームレス自動復帰**
- 経由地に到着後、特別な操作をせずとも、バイクを再発進させるだけで元のツーリングルートへ自動的に復帰・案内を再開する。
